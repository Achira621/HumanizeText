The right way to use these skills
Do not ask Antigravity to design, architect, and implement everything in one giant step. Use the skills in stages:
1. Architecture: system-designer + requirements-analysis. Generate the component diagram, data flows, module boundaries, threat model, and architecture decision records.
2. Design: ui-ux-pro-max + frontend-design + ui-design. Establish the visual language and build the reusable design system before implementing every page.
3. Implementation: React and TypeScript skills. Build the editor, local similarity engine, cryptography module, and encrypted vault as independent features.
4. Security review: security-hardening + frontend-security-coder. Verify data boundaries, key handling, document parsing, CSP, and network behavior.
5. Validation: test-ui + web-performance-optimization. Test real workflows, inspect screenshots at different sizes, and fix defects.
One important caveat: general frontend security skills do not replace cryptography expertise. For HumanizeText, require explicit tests for HMAC consistency, AES-GCM tamper detection, vault key derivation, document-data network leakage, and the limitations of fingerprint-based similarity.
